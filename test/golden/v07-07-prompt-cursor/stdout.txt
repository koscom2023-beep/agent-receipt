이번 작업에서 반드시 지켜야 할 규칙이다.

■ 수정해도 되는 파일 (오직 이 파일들만):
  - src/**

■ 절대 건드리면 안 되는 파일/폴더:
  - package.json

■ 금지 행동:
  - push
  - deploy

■ 공통 규칙:
  - 허용 파일 외에는 생성/수정/삭제 금지
  - 문서/메모/임시 리포트 같은 새 파일 만들지 말 것
  - 허용 scope 밖 작업이 필요하면, 진행하지 말고 멈춰서 사람에게 물어볼 것
  - 요청하지 않은 추가 개선/리팩터링 금지 (요청한 것만)
  - 작업이 끝나면 commit / push / deploy 하지 말고 멈출 것

■ 작업 후 내가 돌릴 검사 (미리 통과하도록 작업할 것):
  - tsc: tsc --noEmit

■ 완료 보고 — 아래 JSON 을 그대로 붙일 것 (사람이 `agent-receipt claims --file` 로 git 과 대조한다):
  {
    "changedFiles": ["수정/생성한 파일 상대경로", "..."],
    "newFiles": ["새로 만든 파일", "..."],
    "deniedHits": [],
    "tests": true,
    "summary": "무엇을 했는지 한 줄"
  }
  - 이 보고는 '주장'일 뿐이며 git 실측과 다르면 mismatch 로 잡힌다. 변경을 숨기지 말 것.
